PDFreaderPY

Documentation for PDF text extraction, literal search, page rendering, and provenance-aware ingestion.

Java status: extraction, page rendering/provenance, Swing GUI, and tested selectable-text search are available. Scanned-page OCR requires a separate provider and is not performed by these commands.

Java tools

  • Java source and Maven tests
  • Java CLI and build guide
  • Java test workflow
  • Published browser PDF reader

Run tests

cd java
mvn --batch-mode --no-transfer-progress clean verify

The Java CLI processes embedded selectable text. It is not OCR and does not claim full parity with all Python workflows.
